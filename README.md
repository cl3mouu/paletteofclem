# Palette of Clem

Blog beauté, lifestyle et daily life.

- **Site** : https://cl3mouu.github.io/paletteofclem/
- **Publier** : https://app.pagescms.org (connexion avec GitHub, puis choisir ce dépôt)

## Comment ça marche

- Chaque publication est un fichier dans `_posts/`. Pages CMS les crée pour toi.
- Les photos et vidéos envoyées sont rangées dans `assets/media/`.
- À chaque enregistrement, GitHub reconstruit le site automatiquement (1 à 2 minutes).
- Une publication datée dans le futur reste cachée et apparaît toute seule à l'heure prévue (vérification toutes les heures).
- Liens Instagram / TikTok du pied de page : à remplir dans `_config.yml`.
